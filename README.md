# rpi-skills
Adaptation of the Research, Plan, Implement recipe pattern from Goose AI implemented as standard skills.

## Installation

Add this to your project or user skills directory for your agents. If you don't have one, do the following:

```shell
mkdir -p ${HOME}/.agents/skills
cd ${HOME}/.agents/skills
curl -L 'https://github.com/dcode/rpi-skills/archive/refs/heads/main.tar.gz' | tar --strip-components 1 -xvf -
```
